# Распознавание исторических славянских текстов (OCR)

Графическое приложение на Python для распознавания исторических славянских текстов с использованием нескольких OCR-движков.

## Особенности

- **Многоуровневая архитектура**: Поддержка трёх OCR-движков (Tesseract, Kraken, TrOCR)
- **Предварительная обработка изображений**: Шумоподавление, улучшение контраста (CLAHE), исправление перекоса, бинаризация
- **Двухпанельный интерфейс**: Одновременный просмотр изображения и редактирование результата
- **Фоновая обработка**: Распознавание выполняется в отдельном потоке без блокировки интерфейса
- **Экспорт результатов**: Сохранение в форматах TXT и DOCX
- **Предустановки обработки**: Готовые конфигурации для различных типов документов

## Требования

### Системные зависимости

#### Windows
1. Установите Tesseract OCR:
   - Скачайте установщик с https://github.com/UB-Mannheim/tesseract/wiki
   - Рекомендуется версия 5.x или выше
   - При установке выберите языковые пакеты (русский, церковнославянский при наличии)

2. Добавьте Tesseract в PATH или укажите путь вручную:
   ```python
   import pytesseract
   pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
   ```

#### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install tesseract-ocr tesseract-ocr-rus libtesseract-dev libleptonica-dev
```

#### macOS
```bash
brew install tesseract tesseract-lang
```

### Python-зависимости

Установите все необходимые пакеты:
```bash
pip install PySide6 opencv-python numpy pillow pytesseract torch transformers
```

Для расширенной функциональности (опционально):
```bash
pip install kraken python-docx
```

## Использование

### Базовый рабочий процесс

1. **Запустите приложение**
2. **Откройте изображение**: Нажмите "📁 Открыть" или выберите Файл → Открыть изображение
3. **Выберите движок**: В выпадающем списке выберите доступный OCR-движок
4. **Настройте предварительную обработку** (опционально):
   - Выберите предустановку или настройте параметры вручную
   - Доступные опции: шумоподавление, CLAHE, исправление перекоса, контраст, бинаризация
5. **Распознайте текст**: Нажмите "🔍 Распознать текст"
6. **Отредактируйте результат**: Исправьте ошибки распознавания в текстовом редакторе
7. **Экспортируйте**: Сохраните результат в формате TXT или DOCX

### Поддерживаемые форматы изображений

- PNG
- JPEG/JPG
- BMP
- TIFF/TIF
- GIF

### Предустановки предварительной обработки

| Предустановка | Описание | Параметры |
|--------------|----------|-----------|
| По умолчанию | Базовая настройка | CLAHE, контраст |
| Старый печатный текст | Для дореволюционных изданий | Шумоподавление, CLAHE, исправление перекоса, контраст |
| Рукописный текст | Для рукописных документов | Шумоподавление, CLAHE, исправление перекоса, контраст |
| Низкое качество скана | Для повреждённых документов | Все параметры включены |

## OCR-движки

### Tesseract OCR
- **Назначение**: Универсальный движок для печатных текстов
- **Поддержка языков**: Множество языков через языковые пакеты
- **Дообучение**: Возможно через fine-tuning
- **Лицензия**: Apache 2.0

### Kraken
- **Назначение**: Специализированный движок для исторических документов
- **Особенности**: Поддержка нелатинских письменностей, сегментация строк
- **Дообучение**: Полная обучаемость на собственных данных
- **Лицензия**: MIT

### TrOCR (Transformer-based OCR)
- **Назначение**: Современная модель на основе трансформеров
- **Особенности**: Высокая точность для рукописного текста
- **Требования**: GPU рекомендуется для быстрой работы
- **Лицензия**: Зависит от конкретной модели

## Метрики качества

Основная метрика оценки качества распознавания — **CER (Character Error Rate)**:
- CER < 5%: Отличное качество
- CER 5-10%: Хорошее качество
- CER 10-20%: Приемлемое качество (требуется редактура)
- CER > 20%: Низкое качество (необходима значительная правка)

## Решение проблем

### Tesseract не найден
- Убедитесь, что Tesseract установлен
- Проверьте, что путь к Tesseract добавлен в переменную окружения PATH
- Для Windows укажите полный путь в коде:
  ```python
  import pytesseract
  pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
  ```

### Ошибки при обработке изображений
- Проверьте формат файла (поддерживаются PNG, JPEG, BMP, TIFF, GIF)
- Убедитесь, что файл не повреждён
- Попробуйте изменить параметры предварительной обработки

### Приложение зависает при распознавании
- Большие изображения обрабатываются дольше — это нормально
- Используйте фоновую обработку (не блокирует интерфейс)
- Для TrOCR рекомендуется наличие GPU
